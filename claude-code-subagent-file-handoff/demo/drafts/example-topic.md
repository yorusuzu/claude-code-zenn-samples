## 分かっていること

多くの鉄道事業者では、折りたたみ自転車を専用の袋に収納すれば手回り品として車内に持ち込めます。
ただし、持ち込める袋のサイズ上限や料金は事業者ごとに異なるため、乗る前に利用する事業者の規定を
個別に確認してください。

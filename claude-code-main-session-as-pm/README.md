# サンプル: メインセッションを PM にする CLAUDE.md テンプレート

Claude Code のメインセッションを「PM / オーケストレーター」として固定し、複数のサブエージェントに
役割分担させるための最小 `CLAUDE.md` テンプレートです。

対応する記事: 「Claude Codeでサブエージェントが増えたら、メインセッションをPMに固定する」

## セットアップ

1. `CLAUDE.md` を自分のプロジェクトのルートにコピーする。
2. 表中のエージェント名・出力先ディレクトリを、実際に `.claude/agents/` に作る定義に合わせて書き換える。
3. `research/`, `plans/`, `drafts/`, `reviews/` など、ワークフローに登場するディレクトリを作成する。

```
# 例
mkdir research plans drafts reviews
```

## 使い方

Claude Code をこのプロジェクトで起動すると、`CLAUDE.md` の内容が読み込まれます。
メインセッションに「〇〇について調べて、記事にして、レビューして」のようにまとめて依頼すると、
メインセッションが `CLAUDE.md` の役割表とワークフローに従って各サブエージェントへ仕事を振り分けます。

## 動作確認について

このサンプルは Markdown ファイル 1 つのみで、実行可能なコードは含みません。
`VERIFIED.md` に記載の通り、ファイルが存在すること・想定した見出し構成になっていることのみを確認しています。
Claude Code 本体でこのテンプレートを使ってサブエージェントに実際に指示を出す検証は、この記録を取った時点では行っていません。
